## 1. 프로젝트 개요 · Overview

서울시 10개 자치구 **숙박시설 4,246곳**에 대해 GIS 기반 공간 분석으로 화재 위험도를 산출하고, 위험군 클러스터링과 공간회귀(MGWR)를 통해 **선제적·데이터 기반 화재 안전 행정 정책**을 제언한 프로젝트입니다.

This project quantifies fire risk for **4,246 lodging facilities** across 10 districts in Seoul using GIS-based spatial analysis. We cluster facilities into risk tiers and apply Multi-scale Geographically Weighted Regression (MGWR) to deliver **data-driven, proactive fire-safety policy recommendations**.

### 핵심 결과 · Key Findings

| 항목 | 값 |
|---|---|
| 분석 대상 | 서울 10개 관광 자치구, 숙박시설 **4,246곳** |
| 사용 변수 | **9개** GIS 기반 화재 위험 변수 (밀집·노후·소방접근성) |
| 군집 결과 | 저위험군 1,326 / 중위험군 1,465 / **고위험군 1,455**개소 |
| 평균 위험점수 | 24.65 / 30.92 / **41.90** |
| 공간 자기상관 | **Moran's I = 0.271** (양의 군집성 명확) |
| 채택 모형 | **MGWR** (5개 후보 모형 중 AIC 최저, 잔차 Moran I ≈ 0) |

## 4. 방법론 및 변수 설계 · Methodology & Variables

### 4.1 분석 파이프라인

```
[공공데이터 수집]
       ↓
[GIS 전처리·결합 (4,246시설)]
       ↓
[9개 변수 산출] ── VIF 검토 ── 모두 < 5
       ↓
[AHP 가중 화재위험점수]
       ↓
[K-Means 클러스터링 (k=3)]
       ↓
[Moran's I → 공간자기상관 확인]
       ↓
[OLS · SLM · SEM · GWR · MGWR 비교]
       ↓
[MGWR 채택 → LISA 잔차분석 + Surface 비교]
       ↓
[군집별 정책 제언]
```

### 4.2 GIS 기반 화재 위험 변수 (9개)

| 카테고리 | 변수 | 정의 | 가중치 |
|---|---|---|:---:|
| **밀집·구조** | 주변건물수 | 반경 50m 내 건물 개수 (연소 확산성) | 0.05 |
| | 집중도 | 반경 50m 내 최빈 용도군 비율(%) | 0.07 |
| | 단속위험도 | 반경 50m 내 불법주정차 단속지점 밀집도 | **0.16** |
| **노후도·규모** | 구조노후도 | (목재/조적조 등) 재질 취약성 × 건축연한 | **0.24** |
| | 시설규모 / 연면적 | 대상 시설의 물리적 크기 | 0.09 |
| | 총층수 | 지상+지하 층수 | 0.02 |
| **소방 접근성** | 도로폭위험도 | 인접 도로폭 6m 미만 가중치 | 0.14 |
| | 최근접 소화용수 거리등급 | 소화전 등 인프라 접근성(0/1/2단계) | 0.12 |
| | 소방위험도 점수 | 119안전센터 출동 이동시간 기반 | 0.11 |

> 가중치는 선행연구(국토교통부 *"노후 건축지구의 소방시설을 고려한 공간정보 기반 화재위험지수 평가플랫폼 개발"*) 및 **AHP(계층화분석법)** 으로 산정.

### 4.3 핵심 변수 산출식

**단속위험도** (소방차 진입 지연 위험)
```
log(시설 50m 내 고유 단속지점수 / 동일 법정동 숙박시설들의 고유 단속지점수 중앙값)
```
*동 중앙값 대비 상대위험도 변환 후 로그 적용으로 극단값 완화*

**구조노후도** (취약 구조 × 노후도 상호작용)
```
기타구조 점수 + 노후연수 + (기타구조 점수 × 노후연수)
```
*철근콘크리트 대비 목재·조적조에 가중치 부여 후 연한과 곱 연산*

**도로폭위험도** (도로폭 m별 가중치)

| 도로폭 | < 6m | 6–8m | 8–10m | 10–12m | 12–15m | 15–20m | 20–25m | 25–30m | ≥ 50m |
|---|---|---|---|---|---|---|---|---|---|
| 가중치 | 1.00 | 0.85 | 0.70 | 0.55 | 0.45 | 0.35 | 0.25 | 0.18 | 0.00 |

**소방위험도 점수** (출동 도착시간 기반)
```
min(최근접 소방시설 거리 / 2,000m, 1)
※ 소방차 30km/h 가정 · 우회계수 1.3 · 출동준비시간 추가
```

### 4.4 다중공선성 검토 (VIF)

모든 파생변수의 **VIF가 기준치 5를 크게 밑돌아** 각 변수가 독립적인 설명력을 가짐을 확인:

| 변수 | VIF | 변수 | VIF |

| 집중도 | 1.523 | 최근접 소화용수 | 1.261 |

## 6. 공간회귀 분석 · Spatial Regression

### 6.1 왜 공간회귀가 필요한가?

**Moran's I = 0.271** (양의 공간자기상관 명확) — *"위험한 지역 주변에는 위험한 지역이 모여 있다"*
→ 데이터가 무작위로 흩어지지 않고 **공간적으로 군집** → 일반 OLS 부적합.

### 6.2 모형 비교 (Cluster별 5개 모형)

| Cluster | Model | n | Adj.R² | AIC | 잔차 Moran I | Moran p |
|---|---|---:|:---:|---:|---:|---:|
| 저위험 | OLS | 1,326 | 1 | -80,149 | 0.108 | 0.001 |
| 저위험 | **MGWR** | 1,326 | 1 | **-81,369** ✅ | **0.005** | **0.286** ✅ |
| 중위험 | OLS | 1,465 | 1 | -87,759 | 0.274 | 0.001 |
| 중위험 | **MGWR** | 1,465 | 1 | **-89,878** ✅ | 0.027 | 0.008 |
| 고위험 | OLS | 1,455 | 1 | -86,978 | 0.057 | 0.001 |
| 고위험 | **MGWR** | 1,455 | 1 | **-88,622** ✅ | **0.001** | **0.419** ✅ |

> **MGWR 채택 근거** — AIC 최저 + 잔차 Moran's I 0에 수렴 + p값 비유의(저·고위험군) → **잔차 공간 자기상관을 가장 안정적으로 설명**

### 6.3 LISA 잔차 분석 (고위험군 한정)

| 변수 | OLS 잔차 Moran I | MGWR 잔차 Moran I | 해석 |
|---|---:|---:|---|
| 구조노후도 | 0.183 | **−0.033** | 군집 영역 대폭 감소 — *지역별 공간효과를 효과적으로 설명* |
| 도로폭위험도 | 0.148 | **−0.040** | 마찬가지로 잔차 군집 거의 해소 |

LISA 색상 의미:
- 🟥 **HH** (양의 잔차 집중) · 🟦 **LL** (음의 잔차 집중)
- 🟧 **HL** (국지 양) · 🟦 **LH** (국지 음)

### 6.4 GWR vs MGWR Surface 비교

- **GWR**: 지역별 영향력이 세밀하게 분산 → 노이즈 많음
- **MGWR**: 변수별 공간 스케일 차이를 반영해 **유사 영향권을 권역 단위로 묶어 안정적**
- → **구조노후도**, **소화용수 접근성**은 단순 국지 현상이 아닌 **권역 단위 공간 영향 요인**

## 7. 정책 제언 및 결론 · Policy Implications

### 7.1 군집별 맞춤형 정책

#### 🟢 저위험군 — *예방 중심 (Prevention)*
- ✅ 자율안전진단 활성화 (시설별 자체 점검 체계 + 예방 교육)
- ✅ 간이 스프링클러 설비 지원 (기초 화재 예방 설비 보급)
- ✅ 관계자 정기 화재 예방 교육

#### 🟡 중위험군 — *환경 개선 (Environmental Upgrade)*
- ⚠️ 생활권(골목) 단위 환경 정비 (좁은 도로·상권 밀집 개선)
- ⚠️ 불법주정차 구역 집중 단속 (소방차 진입 동선 확보)
- ⚠️ 차로 색칠 / 볼라드 정비

#### 🔴 고위험군 — *집중 대응 (Targeted Intervention)*
- 🚨 노후 구조물 내화 성능 보강 (구조적 취약성 개선)
- 🚨 권역 내 소화용수 인프라 확충 (소화전 배치 강화)
- 🚨 행정력 집중 — 우선 점검 대상 지정

### 7.2 제도 개선안 — 점검 패러다임 전환

|---|---|---|

## 8. 실행 방법 · Getting Started

### 8.1 요구 환경

- **Python** 3.11 이상
- **OS**: Windows / macOS / Linux

### 8.2 의존 패키지 설치

```bash
# 데이터·시각화
pip install pandas numpy scikit-learn matplotlib seaborn plotly streamlit folium

# 공간 분석 (GIS / Spatial Stats)
pip install geopandas shapely pyproj libpysal esda spreg mgwr branca

# 부스팅·앙상블 (선택)
pip install lightgbm xgboost catboost statsmodels
```

> 또는 한 번에:
> ```bash
> pip install -r requirements.txt
> ```

### 8.3 대시보드 실행

```bash
# 저장소 클론 후
cd NJT-PJT
streamlit run dashboard.py
```

브라우저가 자동으로 열리며 `http://localhost:8501` 에서 인터랙티브 대시보드 확인 가능.

### 8.4 분석 스크립트 실행 예시

```bash
# 군집 + 공간회귀 풀 파이프라인
python scripts/run_final_spatial_pipeline.py

# GWR/MGWR 전체 데이터 적합 + 비교 지도 생성
python scripts/run_full_gwr_mgwr_from_final_table.py

# 자치구별 도로폭 인터랙티브 지도 생성
python scripts/build_road_width_10gu_official_complete_map.py
```
